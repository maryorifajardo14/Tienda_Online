## Descripción del proyecto

Maquetación visual (solo diseño, sin funcionalidad) de la página principal de
**Beauty Glow Fashions**, una tienda online de ropa para mujer, desarrollada
con **HTML5** y **Bootstrap 5.3.3**. La página tiene una identidad muy
femenina, con paleta de blanco, rosa pastel y morado pastel, logo propio y el
eslogan **"Brilla con tu propio estilo"**.

## Componentes de Bootstrap utilizados

- **Navbar** (`navbar`, `navbar-expand-md`) con el logo de la marca e ícono de
  carrito de compras (color morado oscuro) con contador simulado (badge).
- **Carousel** (`carousel`, `carousel-inner`, `carousel-indicators`,
  `carousel-caption`) como encabezado principal con 3 slides y el eslogan de
  la marca.
- **Grid system** (`container`, `row`, `col-sm-3`, `col-sm-9`, `col-12`,
  `col-md-4`) para dividir el cuerpo en menú lateral / catálogo, y para el
  diseño responsivo del catálogo (1 producto por fila en móvil, 3 por fila en
  pantallas medianas/grandes).
- **Cards** (`card`, `card-img-top`, `card-body`, `card-title`) para mostrar
  cada uno de los 6 productos con imagen, nombre y precio.
- **Buttons** (`btn`) para el botón "Agregar al carrito" de cada producto.
- **List group** (`list-group`, `list-group-item`) para el menú de categorías.
- **Bootstrap Icons** para el ícono del carrito y los íconos de categorías.
- CSS adicional (`styles.css`) con tipografías personalizadas (Playfair
  Display + Poppins) y la paleta de color de la marca (rosa pastel, morado
  pastel, morado oscuro) para dar una identidad visual femenina y coherente.
